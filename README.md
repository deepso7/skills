# agent-skills

Source for the skills installed in `~/.agents/skills` (read by Codex and T3 Code) and symlinked into `~/.claude/skills` for Claude Code.

- `skills/baby-sit`: watch a PR until it is green and ready to merge.
- `skills/raise-pr`: implement, cross-review, open a PR, then baby-sit it.

Test: `bun test`. Install: `./install.sh`.
